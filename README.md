# Dot Seven Ranch — dotsevenranch.com

The Dot Seven Ranch website: premium ranch-raised beef delivered from our family ranch to your table.

## Tech stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Shopify (headless backend)
- Deployed on Vercel (auto-deploys from this repo's main branch)

## Local development

```sh
npm install
npm run dev
```

The dev server runs at http://localhost:8080.

## Build

```sh
npm run build
```
